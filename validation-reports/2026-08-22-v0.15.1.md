# Validation Report — terrariabonker v0.15.1

**Date**: 2026-08-22
**Scope**: Spec 020 — code-patch anchor resilience: wildcard the bytes a cheat overwrites,
and make `is_enabled` read ground truth. Fixes `[ERROR] anchor 'place' not found` after a
restart and the GUI checkbox desync.

## Summary

The `place` (fast_place) and `reset_block` (reach/mining) AOB anchors previously included
the exact bytes those cheats overwrite, so once a cheat was applied the anchor stopped
matching. The per-pid site cache masked this — until a race between the GUI's 500 ms
`patch status` and an enable/disable dropped the cached site while the memory stayed
patched; the next re-resolve then failed. Fix: wildcard the patched byte ranges in both
anchors (keeping invariant prefixes and downstream context for uniqueness) so they resolve
whether or not the cheat is applied, and change `is_enabled` to resolve + compare memory
(ground truth) instead of trusting the cache — so status self-heals after a racy toggle.

## Phase 3 — Tests

- **103 passed** headless (2 new): `test_anchor_resolves_whether_or_not_patched` (both
  anchors resolve pristine and patched, for fast_place/reach/mining) and
  `test_is_enabled_reads_ground_truth_without_cache`.
- **Live** (restarted game pid 732297, which had produced the error): with the new anchors,
  `_resolve('place')` succeeds despite the patched site, and `is_enabled` reports
  `fast_place`, `reach`, and `mining` all True from memory — matching the actual (orphaned)
  patches the state file had lost. Both wildcarded patterns matched exactly one site.

## Phase 5 — Security review

- No new dependencies, no network, no new inputs. Same sudo `/proc` write path as before,
  applied to the same cheats. Wildcards only relax the *locating* pattern; the bytes
  written are unchanged. A game update degrades to "anchor not found" (no write). No
  secrets; no `eval`/`exec`/shell. Dependency set unchanged.

## Phase 5.5 — Release safety

  patches. The fix additionally makes previously-orphaned patches (patched memory the state
  file lost) recoverable, since resolve now works patched-or-not.
