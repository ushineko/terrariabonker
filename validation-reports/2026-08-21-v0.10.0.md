# Validation Report — terrariabonker v0.10.0

**Date**: 2026-08-21
**Scope**: Spec 012 — recipe browser (extract `Main.recipe[]` → cache → GUI tab).

## Summary

Adds a recipe browser (vanilla Terraria has none). Recipes are built in code, not a
static table, so they're extracted from the running game's `Main.recipe[]` over `/proc`
(reusing the mono-array-from-a-static primitive from the LocalPlayer fix), cached to
`data/recipes.json`, and browsed offline in a new Recipes tab. Station names are derived
exactly from each output item's `createTile`.

## Phase 3 — Tests

- **82 passed** headless (3 new in `test_recipes.py`: by-output / uses queries and
  station naming against a fixture). Parity test covers `extract-recipes`.
- Offscreen GUI: the Recipes tab reports "3603 recipes cached"; "Makes Iron Anvil" →
  "Iron Anvil ×1 = Iron Bar ×5 [Work Bench]"; "Uses Gold Bar" → 21 recipes with counts.
- **Live** (game pid 1632717): `extract` read 3,603 recipes; spot-checks exact — Torch
  ×3 = Gel + Wood (by hand); Wooden Sword = Wood ×7 @ Work Bench; Iron Anvil = Iron Bar
  ×5 @ Work Bench; Gold Broadsword = Gold Bar ×8 @ Anvil. Common station names correct.

## Phase 4 — Code quality

- `ruff check` → passed. Extraction (`recipes.extract`) is `/proc`-based; browsing
  (`load`/`by_output`/`using`/`station_name`) reads the cache in-process so the GUI needs
  no sudo to browse — only re-extract shells to the CLI (`client.extract_recipes_argv`,
  parity-kept). `locate.main_static_base` reuses the get_LocalPlayer AOB.

## Phase 5 — Security review

- No new inputs beyond a search string (used to filter cached data). No network, no new
  dependencies. Extraction reads memory over the existing `/proc` path; the cache is
  plain recipe data. Secrets: none.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. Additive — new module, data file, CLI verb, GUI tab; no
  existing behaviour changed. Build-specific offsets documented (`ce/poc_recipe.lua`) and
  re-derivable; `extract-recipes` regenerates the cache after an update.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.10.0`.
