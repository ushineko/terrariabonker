# Validation Report — terrariabonker v0.11.2

**Date**: 2026-08-21
**Scope**: Spec 015 — persist code-patch values; remove "code cave" jargon from the
patch tooltips.

## Summary

Code-patch cheat values are now persisted per game pid in
`~/.config/terrariabonker/patches.json` (new `"values"` key) and restored across a
fresh process, so the GUI spinboxes reflect the value actually applied to the game
instead of resetting to `ValueSpec` defaults. `patch status --json` now emits
`{"on": …, "values": …}`; `gui.client.parse_patch_status` normalizes both this and the
legacy flat shape. The `tool_reach`/`pickup`/`spawn_rate` checkbox tooltips and the
group tooltip were reworded to drop "code cave" / "byte patch" / "/proc" /
"Cheat Engine."

## Phase 3 — Tests

- **87 passed** headless (`QT_QPA_PLATFORM=offscreen`). 4 new in `test_patcher.py`:
  default-before-apply, record-and-restore-across-instances, survive-disable, plus the
  parser normalization checked directly.
- **Live** (running game): `patch enable tool_reach --value 88` then a fresh
  `patch status --json` returned `values.tool_reach == 88` — cross-process restore via
  the state file. `patch status` text now prints `= <value>` per valued cheat.
  tool_reach restored to its default (30) after the test.

## Phase 4 — Code quality

- `ruff check .` → All checks passed. New surface is small and localized:
  `Patcher._record_value`/`values`, the `"values"` state key, the CLI JSON shape, the
  parser normalization, and the GUI spinbox restore. No duplication introduced.

## Phase 5 — Security review

- No new inputs, network, or dependencies. The persisted `"values"` are numeric cheat
  parameters written to the existing user-owned state file. Read/write stays on the
  established sudo `/proc` path. Secrets: none.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. The `"values"` state key is ignored by older code
  (`s.get`), and the new status JSON is back-compatible (the parser accepts the legacy
  flat `{name: bool}`). Pid-scoped reset-on-restart semantics unchanged.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.11.2`.
