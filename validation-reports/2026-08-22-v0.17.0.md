# Validation Report — terrariabonker v0.17.0

**Date**: 2026-08-22
**Scope**: Spec 024 — raise-minion-cap cheat + concurrency-safe patch state (fixes the
multi-checkbox toggle desync).

## Summary

Adds a `max_minions` cheat that rewrites `ResetEffects`' per-frame `maxMinions = 1`
immediate to a tunable N (a new `Cheat.make_patched` in-place-patch mechanism), so the
summon cap holds each frame with accessory bonuses on top. Also makes the shared patch-state
file concurrency-safe in the common layer: an exclusive `flock` around each mutating op
(re-loading fresh state under the lock) plus atomic writes, so concurrent CLI invocations
(the GUI toggling several cheats at once) serialize instead of clobbering. The GUI also
queues toggles to avoid a process storm and re-syncs checkboxes to ground-truth memory.

## Phase 3 — Tests

- **115 passed** headless (1 new): `test_max_minions_tunable_immediate_patch` (immediate
  rewritten to the cap, live re-tune, disable restores `1`, ground-truth `is_enabled`);
  enumeration tests updated for the new cheat.
- **Live**: CE recon (`ce/poc_minion.lua`) found `maxMinions` at `+0x3F8` and the reset in
  `ResetEffects`. Enabled `max_minions=10`; `maxMinions` settles to 10 (verified by a direct
  write of 50 dropping to the patched cap). A 20-way concurrent `flock` isolation test lost
  0 of 20 updates. Concurrent CLI enables reflected correctly in ground-truth `status`.

## Phase 4 — Code quality

- flake8 clean. The tunable patch is a small addition to the existing `Cheat` path
  (`make_patched` branch in enable/disable/is_enabled); the lock is a single context manager
  in the common layer; the GUI queue replaces the per-toggle spawn. No new dependencies.

## Phase 5 — Security review

- No new runtime dependencies (`fcntl` is stdlib). Same sudo `/proc` write path; the cheat
  writes a bounded 4-byte immediate. The lock/atomic-write only harden the existing state
  file. No secrets; no `eval`/`exec`/shell. `ce/poc_minion.lua` is a dev-only CE recon
  script.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. Disable restores the `maxMinions=1` immediate; a game restart
  clears all patches. The state-file changes are backward-compatible (same schema; a lock
  file and atomic temp are additive).

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.17.0`.
