# Validation Report — terrariabonker v0.4.0

**Date**: 2026-08-21
**Scope**: Spec 005 — tunable code-patch values, in-Trainer merge of the patch
toggles (removing the "CE Patches" tab), a Steam launcher button, inventory
slot-ascending default, and a window-width fix.

## Summary

QoL follow-up to v0.3.0's code patches. The valued cheats (`mining`, `reach`) are
now user-tunable through a `--value` CLI option and GUI spinboxes; their toggles
moved onto the Trainer tab (no Cheat Engine is needed at runtime, so a dedicated
tab overstated it — the "CE" name is reserved for future real CE instrumentation).
Adds a Launch-Terraria button (unprivileged Steam launch), defaults the inventory
to slot order, and fixes a window that opened too wide to resize.

## Phase 3 — Tests

- **53 passed** headless. The value override is covered by the patcher tests; the
  `patch enable --value` argv is exercised by the parity samples.
- Offscreen GUI smoke test: window constructs; patch checkboxes (`mining`, `reach`,
  `fast_place`) and valued spinboxes (`mining`, `reach`) present; launch button
  present; inventory sort indicator is column 0 (Slot) ascending.
- Value plumbing verified end to end: `client.patch_set_argv('mining', True,
  value=0.15)` -> `['patch','enable','mining','--value','0.15']`; the CLI parses
  `--value` to `args.value`.

## Phase 4 — Code quality

- `ruff check` → passed. `patcher.py` remains toolkit-free; the GUI reaches it only
  through the CLI `--json` contract. No stale references to the removed tab.
- The launcher is unprivileged and detached — kept out of the sudo CLI wrapper by
  design (Steam refuses to run as root), which is the correct trust boundary.

## Phase 5 — Security review

- **Secrets**: none. **Network**: none added at runtime (the launcher hands a
  `steam://` URL to the Steam client; no network calls in this code).
- **Privilege**: unchanged for memory ops (still sudo per action). The new launcher
  deliberately runs *without* sudo. No new inputs cross a trust boundary; `--value`
  is a float parsed by argparse and packed as f32/i32.
- **Dependency scan**: no new dependencies. PyQt6/numpy unchanged.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. Pure GUI/CLI/plumbing change; no memory behaviour
  changed except that `enable` can use a caller-supplied value. Additive — no
  command or flag removed (`patch enable` gains an optional `--value`).

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.4.0`.
