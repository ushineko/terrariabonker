# Validation Report — terrariabonker v0.2.0

**Date**: 2026-08-20
**Scope**: Spec 003 — shared service layer + view parity. Adds the `give` CLI
command. Refactor: no behaviour change beyond centralising give-to-empty-slot.
Also: inventory-table usability (all columns resizable/movable, numeric-aware
sorting, edits keyed to Slot not row) and the item-name map refreshed to 1.4.4.1

## Summary

Introduces a view-neutral `service.py` core that both the CLI and GUI consume, a
single `gui/client.py` subprocess-contract module, and parity/neutrality tests
that turn CLI/GUI drift into a build failure. Adopts the jira-viewer dual-shell
design, adapted for the sudo privilege boundary (the GUI reaches the core across
a subprocess, not in-process).
