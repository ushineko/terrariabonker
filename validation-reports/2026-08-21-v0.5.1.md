# Validation Report — terrariabonker v0.5.1

**Date**: 2026-08-21
**Scope**: UI polish for the grid inventory (spec 006). No behaviour change.

## Summary

Two fixes from live use of v0.5.0:

1. **The grid governs the window minimum size.** The inventory grid's natural size
   is applied as the scroll area's minimum (width + height), and the horizontal
   scrollbar is disabled, so the full 10-column layout shows without hand-resizing or
   a horizontal scrollbar. The window opens at that natural size
   (`resize(sizeHint())`); measured 779×760 minimum, 779×840 initial.
2. **Cell labels no longer clip.** Cell font dropped to 8 pt (as a `QFont`, so the
   per-cell recolouring in `_render_cell` keeps it) and the name abbreviation
   tightened (default width 9 → 8: "Copper Pickaxe" → "Cop.Pic", "Gold Ore" fits).
   Cell size 64→66 px.

## Phase 3 — Tests

- **66 passed** headless. The `abbrev` change is covered by `test_invgrid`
  (multi-word abbreviation, long-word truncation still ≤ bound).
- Offscreen: window `minimumSizeHint` is 779×760 (grid-driven); abbreviations
  render as expected ("Cop.Pic", "Sli.Whi", "Gold Ore").
