# Validation Report — terrariabonker v0.12.0

**Date**: 2026-08-21
**Scope**: Spec 016 — drop-chance floor cheat (guaranteed / minimum-% common drops),
plus the multi-site + idempotent injection machinery it required.

## Summary

New `loot` code patch floors the common-drop chance at a tunable percent (100 =
guaranteed) by clamping `CommonDrop.TryDroppingItem`'s roll denominator (`[esi+10]`) at
`TryDroppingItem+0x26`. Ported from the FearLess ReGrind table; the 1.4.5.7 site/offset
were re-derived (denominator moved `+0x0C -> +0x10`). Two supporting changes to the
injection machinery: **multi-site** injections (the anchor matches four CommonDrop
twins; each gets its own code cave) and **idempotent enable** (re-toggle / live value
change reuse recorded sites instead of re-scanning). The anchor was relocated to the
method tail (`+0x2D`, `inject_off = -7`) so it can't be corrupted by its own jump.

## Phase 3 — Tests

- **90 passed** headless (`QT_QPA_PLATFORM=offscreen`). New: loot roundtrip (cap
  verify), multi-site (both planted twins patched), idempotent re-enable (obliterate
  the anchor after enable, re-enable at a new value must still succeed).
- **Live** (game pid 1632717): `loot` enabled on **4** CommonDrop twins — distinct
  caves, each stub `mov ecx,[esi+10]; cmp ecx,cap; jle; mov ecx,cap; mov [esp+04],ecx`,
  jmp-back verified to land at `inject+7`. All four sites confirmed to share the exact
  overwrite shape (`+0x2B..+0x2C = 24 04`, `+0x2D = 89 04 24`). Value change 100->50
  rewrote all stubs to cap=2 with no re-scan; **user confirmed guaranteed drops
  in-game**.

## Phase 4 — Code quality

- `ruff check .` -> All checks passed. The injection record schema moved to a
  multi-site shape `{sites: [...], stub_len}`; a `_norm_inj` helper normalizes the
  legacy flat records on load. `_find_cave` gained a `claimed` exclusion set so
  per-site caves don't collide. Existing single-site injections (tool_reach/pickup/
  spawn_rate) migrate transparently and were re-verified live.

## Phase 5 — Security review

- No new inputs, network, or dependencies. The cheat writes a fixed-shape stub into
  borrowed executable padding over the established sudo `/proc` path; the only external
  value is a clamped 1–100 percent. Secrets: none. Dependency set unchanged
  (numpy, PyQt6) — no scanner delta.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. Disable restores the original bytes at every site and
  scrubs each cave; a game restart clears all patches. The new state schema is
  back-compatible (legacy flat inj records normalized on load); the anchor sits
  downstream of the patched bytes so recovery never hits a self-corrupted scan.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.12.0`.
