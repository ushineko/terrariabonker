# Validation Report — terrariabonker v0.19.0

**Date**: 2026-08-22
**Scope**: Spec 028 — fast-placement presets (Fast/Faster/Hyper) + GUI About dialog and
titlebar version.

## Summary

Fast placement is now a preset cheat: itemTime is forced to 4 (Fast), 2 (Faster), or 1
(Hyper) via the tunable `make_patched` mechanism and a new `ValueSpec.presets` field; the GUI
renders it as a dropdown, and the choice persists/auto-restores through the existing
value/profile machinery. The GUI also gains an About dialog (description + FearLess
"TerrariaReGrind" attribution) and shows its version in the window titlebar.

## Phase 3 — Tests

- **119 passed** headless. `test_fast_place_presets` verifies the default Fast preset
  (`mov edi,4; nop*5`), a live re-tune to Hyper (`mov edi,1`), disable restoring the
  original bytes, and ground-truth `is_enabled`. Enumeration tests updated for the new value.
- Offscreen: titlebar shows `terrariabonker v0.19.0`; `fast_place` renders a
  Fast/Faster/Hyper combo (default Fast); other valued cheats keep their spinboxes.

## Phase 4 — Code quality

- flake8 clean. `fast_place` reuses the `make_patched` path from the minion-cap cheat;
  `ValueSpec.presets` + a small GUI branch render a combo vs spinbox; the About dialog is a
  standard `QMessageBox.about`.

## Phase 5 — Security review

- No new dependencies, no network. `fast_place` writes the same bounded immediate patch (now
  1/2/4 instead of a fixed 4) over the established sudo `/proc` path. No secrets; no
  `eval`/`exec`/shell.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. Disable restores the original bytes; a game restart clears
  patches. `fast_place` gaining a value is backward-compatible with the value/profile
  machinery.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.19.0`.
