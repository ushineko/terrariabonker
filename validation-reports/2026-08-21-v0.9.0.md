# Validation Report — terrariabonker v0.9.0

**Date**: 2026-08-21
**Scope**: Spec 010 — item pickup range via a `GrabItems` code-cave injection.
Reuses and generalizes the v0.8.0 injection machinery.

## Summary

The `pickup` cheat scales the item grab range by injecting `imul eax,N` before the
grab-range store in `Player.GrabItems`, so items are pulled from far off-screen
(live-verified). It reuses the code-cave injection from v0.8.0; the `Injection`
dataclass gained a `make_body(value)` builder so each injection supplies its own stub
(`imul eax,N` here; the two `mov`s for `tool_reach`, refactored onto the same path).
Ported from the FearLess ReGrind table and re-derived for 1.4.5.7.

## Phase 3 — Tests

- **77 passed** headless. New: `test_pickup_injection_uses_imul_stub` (jmp installed;
  cave stub is `6B C0 32` = `imul eax,eax,50` followed by the 6 overwritten bytes;
  byte-perfect restore). Status set widened to include `pickup`. Parity test covers the
  `pickup` argv.
- Offscreen GUI: `pickup` appears as a checkbox + spinbox (2–500, default 50) via
  `PATCH_CATALOG`.
- **Live** (game pid 1632717): the anchor resolved uniquely to `GrabItems+164`
  (0x1c69d4b4); the stub was `6b c0 32 89 45 ac 8d 45 b0 <jmp>`. `pickup --value 50`
  pulled items (mana stars) from off-screen. Disable restored the exact original bytes
  (`89 45 ac 8d 45 b0`) — byte-perfect.

## Phase 4 — Code quality

- `ruff check` → passed. `Injection.make_body` cleanly generalizes the stub body; the
  cave/rel32/state machinery is unchanged. Anchor is fixed bytes around the store with
  the two `get_Hitbox` call operands wildcarded (unique, verified live).

## Phase 5 — Security review

- No new inputs beyond a range-bounded int multiplier, no network, no new dependencies.
  The injection edits the game's own code over the existing `/proc` path; a wrong anchor
  is guarded by the unique wildcard pattern and a verified restore. Secrets: none.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. `disable` restores exact bytes (live-verified); a restart
  clears the patch and cave. Additive — no existing cheat changed. Build-specific

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.9.0`.
