# Validation Report — terrariabonker v0.8.0

**Date**: 2026-08-21
**Scope**: Spec 009 — unified tool/interaction reach via a `GetRanges` code-cave
injection. Adds wildcard AOB support and the trainer's first code-cave patch.

## Summary

The `tool_reach` cheat forces the output of 1.4.5.7's
`TileReachCheckSettings.GetRanges` past its clamp, so mining, tool use, chest/sign
interaction, and crafting-station range all extend together (live-verified). Because
this writes more bytes than the site has room for, the patcher gained a code-cave
injection path (jump to a stub in executable padding) and wildcard AOB matching (the
anchor spans ASLR'd immediates). The value cheats and the injection are merged into a
single `PATCH_CATALOG` used by the CLI and GUI.

## Phase 3 — Tests

- **75 passed** headless. New: `test_tool_reach_injection_roundtrip` (jmp installed at
  the inject site; cave stub is `mov [esi],N; mov [edi],N; <orig>; jmp back` with the
  forced value; byte-perfect restore on disable); status set widened to include
  `tool_reach`. Parity test covers the `tool_reach` argv.
- Offscreen GUI: `tool_reach` appears as a checkbox with a value spinbox (1–200,
  default 30), driven through `PATCH_CATALOG`.
- **Live** (game pid 1632717): the anchor resolved to the real `GetRanges`
  (0x22F8AE30). `tool_reach --value 40` extended mining, tool use, chest/sign
  interaction, and crafting-station availability. Disable restored the exact original
  bytes (`8d 65 f4 5e 5f`) and re-enable re-installed the jump — byte-perfect.

## Phase 4 — Code quality

- `ruff check` → passed. `patcher.py` remains toolkit-free. Wildcard matching scans on
  the pattern's longest fixed run then verifies the mask (fast + correct). The cave
  finder borrows int3/zero JIT padding; state (inject/cave/stub-len) is persisted for a
  clean restore. Injection vs value-cheat is dispatched by name in enable/disable/status.

## Phase 5 — Security review

- No new inputs, network, or dependencies. `--value` is a range-bounded int. The
  injection edits the game's own code over `/proc` (already-privileged path); a wrong
  anchor is guarded by a long unique wildcard pattern and a verified restore. Secrets:
  none.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. `disable` restores exact bytes (live-verified); a game
  restart clears the patch and the cave. Additive — no existing cheat changed
  (`reach`/blockRange still there for placement). Build-specific AOB documented in
  `ce/REACH_FINDINGS.md` with the re-derivation probes.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.8.0`.
