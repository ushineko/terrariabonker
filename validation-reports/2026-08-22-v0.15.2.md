# Validation Report — terrariabonker v0.15.2

**Date**: 2026-08-22
**Scope**: Spec 021 — icon cache covers all items (fixes missing icons for non-craftable
inventory items); animated sprites cropped to their first frame.

## Summary

Two icon fixes. (1) The cache was built only from recipe-referenced items, so inventory
items with no recipe (e.g. Slime Staff #1309, a drop) had no icon. `extract` now defaults
to `all_item_ids()` (every named item), and a `scope` marker in `.done` makes older
caches rebuild automatically. (2) Animated items (Fallen Star #75, Souls) ship as tall
vertical sprite-sheets; `_deanimate` detects an evenly-spaced multi-block strip
(`height >= 2×width`) and crops to the first frame, self-contained with no game-memory
frame-count data. The Inventory tab now also triggers extraction when the cache is missing.

## Phase 3 — Tests

- **107 passed** headless (4 new): `_deanimate` crops a synthetic strip, leaves a
  single-frame tall image and a wide image unchanged; `all_item_ids` is a superset of the
  recipe-referenced set.
- **Live**: a full re-extract cached **6133 / 6195** icons (62 skips = item IDs with no
  sprite file). Verified: Slime Staff (#1309) caches a real sprite instead of text;
  Fallen Star (#75) 208→26 px and Soul of Light (#520) 112→28 px — a rendered contact
  sheet shows a single star / single soul / staff, all correct.

## Phase 4 — Code quality

- flake8 clean on changed files. `_deanimate` is a small guarded helper; `extract`
  refresh-on-scope-mismatch avoids stale skips; the GUI gained a `_sprites_extracting`
  guard and clears the icon/pixmap caches after extraction so placeholders are replaced.

## Phase 5 — Security review

- No new dependencies (numpy already used). No network, no new inputs; reads the user's own
  game `.xnb` files and writes PNGs into the local `~/.cache` (unprivileged). No secrets;
  no `eval`/`exec`/shell. A malformed sprite is still skipped, never aborting the batch.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`; delete `~/.cache/terrariabonker/` to rebuild. Disk + GUI
  only; no game memory touched, nothing committed. A wrong de-animation crop is cosmetic
  and disposable.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.15.2`.
