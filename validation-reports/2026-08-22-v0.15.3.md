# Validation Report — terrariabonker v0.15.3

**Date**: 2026-08-22
**Scope**: Spec 022 — icons for sprite-less placeable items (trapped chests) drawn from the
Containers tile-sheets.

## Summary

60 recipe-output items (all "Trapped … Chest" variants) have no `Item_<id>.xnb` and showed
placeholders. Terraria draws these from the Containers tile-sheets at each item's
`placeStyle`. CE recon gave the Item field offsets (`createTile = 0xA0`,
`placeStyle = 0xA8`); recipe extraction now records `tileicons[itemID] = [createTile,
placeStyle]` for placeable outputs into `recipes.json`, and the sprite extractor composites
the 2x2 chest from `Tiles_<tile>.xnb` at the item's style when no item sprite exists.

## Phase 3 — Tests

- **108 passed** headless (1 new): `test_composite_chest_assembles_four_tiles` verifies the
  four 16x16 tiles composite into a 32x32 icon with no inter-tile padding gap.
- **Live**: CE recon (`ce/poc_itemplace.lua`) confirmed `placeStyle` at `0xA8`. Re-extract
  recipes captured 1923 `tileicons` entries (chest #3665 → [441, 0], #48 → [21, 0]). A full
  sprite re-extract cached **6193 / 6195** icons (down from 62 skips to 2). Rendered trapped
  chests from both the 441 and 468 sheets — Trapped Chest / Gold / Shadow / Ivy / Frozen /
  Skyware — verified visually as correct, distinct per-style chests.

## Phase 4 — Code quality

- flake8 clean. The composite is a small pure function (`_composite_chest`, unit-tested)
  behind `_tile_icon` (sheet-cached); recipe extraction adds two field reads. The extract
  loop falls back to the tile icon only when no item sprite exists.

## Phase 5 — Security review

- No new dependencies. Same sudo `/proc` read path for recipe extraction (unchanged in
  privilege); sprite/tile decode is unprivileged disk work. Inputs are the user's own game
  files. No secrets; no `eval`/`exec`/shell. `recipes.json` gains a numeric `tileicons` map
  (game-derived, not copyrighted). A malformed sheet is skipped, never aborting the batch.

## Phase 5.5 — Release safety

- **Rollback**: `git revert` (reverts `recipes.json` + code); delete
  `~/.cache/terrariabonker/` to rebuild icons. Disk + GUI only; no game memory written.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.15.3`.
