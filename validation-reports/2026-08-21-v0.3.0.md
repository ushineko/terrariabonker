# Validation Report — terrariabonker v0.3.0

**Date**: 2026-08-21
**Scope**: Spec 004 — code-patch cheats (`patcher.py`, `patch` CLI verb, GUI "CE
Patches" tab). The frame-reset half of the trainer, applied via `/proc`.

## Summary

Adds global mining speed (`pickSpeed`), item-independent placement reach
(`blockRange`), and fast placement (`ApplyItemTime` timing) — cheats a value-write
can't hold, because the game resets those fields every frame. The trainer locates
the JIT'd patch sites by unique AOB anchor and patches them through `/proc` (no CE at
runtime; CE was the research tool that derived the sites — see `ce/README.md`).

## Phase 3 — Tests

- **52 passed** headless (6 new in `test_patcher.py`: AOB resolve, patch+value
  round-trip, shared-anchor independence, per-pid state persistence, missing-anchor
  error). Parity test extended: the `patch` client contract is checked against the CLI.
- Live: `patch enable/disable {mining,reach,fast_place}` round-trips against the
  running game — code bytes patched then restored to stock, `pickSpeed`/`blockRange`
  values set then reverted, `patch status --json` valid.

## Phase 4 — Code quality

- `ruff check` → passed. `patcher.py` is toolkit-free (fits the neutrality rule);
  the GUI reaches it only through the CLI `--json` contract via `gui/client.py`.
- Self-restoring: `disable` writes back the exact original bytes; a game restart
  clears all patches (fresh JIT), and a stale per-pid state file is ignored.

## Phase 5 — Security review

- **Secrets**: none. **Network**: none at runtime. **Privilege**: unchanged — sudo
  per operation; the patcher reads `/proc/<pid>/maps` and writes the game's own code.
- **New state file**: `~/.config/terrariabonker/patches.json` holds only a pid and
  resolved addresses — no credentials, nothing affecting a save.
- **Blast radius**: single-player, local, own game process. A wrong/updated build is
  caught (the version gate plus a clear PatchError when an anchor is missing/non-unique).

## Phase 5.5 — Release safety

- **Rollback**: `git revert`; `patch disable` restores exact bytes; a game restart
  clears everything. Additive — no existing command/flag removed.
- **Build-specific AOBs**: documented; re-derive with the `ce/` tools after an update.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.3.0`.
