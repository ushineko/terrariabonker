# Validation Report — terrariabonker v0.15.0

**Date**: 2026-08-22
**Scope**: Spec 019 — item icons in the inventory grid; truncated recipe-grid labels.
A GUI follow-up to spec 018, reusing its icon cache.

## Summary

Inventory cells now render the item **sprite** with the stack count composited into the
corner (Terraria-style) and the rarity tint kept as the cell border; the full name/details
stay on the tooltip, and items without a sprite fall back to the previous abbreviated text.
The recipe grid's labels are truncated with `invgrid.abbrev` at an 8pt font so they no
longer clip — the full name remains on hover and in the click popup, and the live filter
still matches the full name. The icon cache was hoisted to `MainWindow.__init__` so both
tabs share it; `_cell_icon` composites sprite + stack via `QPainter`.

## Phase 3 — Tests

- **101 passed** headless (no test changes needed; the change is GUI rendering over the
  existing icon cache and recipe/inventory data paths already covered).
- **Offscreen render** confirmed: inventory cells show pickaxe / torch ×826 / wood ×1553 /
  stone ×50 with rarity-tinted borders and corner stack counts; the recipe grid labels
  ("Ada.Pic", "Act.Rod", …) fit without clipping at the smaller font.

## Phase 4 — Code quality

- flake8 clean on the changed file (only pre-existing long lines in untouched code remain).
  The icon cache is now initialized once in `__init__` (removed the duplicate init in the
  recipes tab); `_pixmap_for` is shared by both the recipe icons and the inventory
  compositing.

## Phase 5 — Security review

- GUI-only change. No new dependencies, no network, no game-memory access, no files written
  (reads the existing `~/.cache` icon PNGs). No secrets; no `eval`/`exec`/shell. Nothing to
  scan beyond the unchanged dependency set (numpy, PyQt6, Pillow).

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. Purely presentational; no memory, no persisted state, no new
  deps. If the icon cache is absent, cells/labels fall back to text — no crash.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.15.0`.
