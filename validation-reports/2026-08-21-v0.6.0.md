# Validation Report — terrariabonker v0.6.0

**Date**: 2026-08-21
**Scope**: Spec 007 — rarity colour tinting for inventory slots (new `Item.rare`
offset). Also a minor label tidy (the "Code patches" group box).

## Summary

Inventory slots are now tinted by Terraria's item-rarity colour (its tooltip-name
colour) — a dark rarity-hued background with a brighter border, light text kept
readable; empty slots stay neutral; the tooltip gains a rarity line. This required
mapping one new offset, `Item.rare` (0xF8), discovered by diffing ContentSamples
templates of items with known rarities. The Trainer "Code patches" group box label was
shortened (the long explanation moved to a tooltip).

## Phase 3 — Tests

- **70 passed** headless (4 new in `test_invgrid`: rarity map distinctness + fallback,
  dark-bg/bright-border invariant, rarity tooltip line).
- Headless render smoke: different rarities produce different cell stylesheets; the
  tooltip shows the rarity; empty cells stay neutral.
- **Live** (game pid 1632717): `inventory --json` reports correct `rare` values —
  Slime Whip 2 (green), Fallen Star / Shackle / potions 1 (blue), commons 0 (white).
  Offset 0xF8 validated across the spectrum during discovery: Old Shoe −1, Muramasa 2,
  Excalibur 5, Terra Blade 8, Meowmere / Zenith 10.

## Phase 4 — Code quality

- `ruff check` → passed. Rarity→colour logic and the dark-bg/bright-border derivation
  live in the Qt-free `gui/invgrid.py` (unit-tested); `_render_cell` only applies it as
  a stylesheet. Cell font stays a `QFont`, so the tint stylesheet does not reset it.

## Phase 5 — Security review

- No new inputs, network, privilege, or dependencies. The new offset is a read only;
  a wrong offset would mis-colour a tile, never affect a write. Secrets: none.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`. Additive — one offset, one data field (`ItemSlot.rare`
  + its JSON), colour helpers, and a stylesheet. No write path or existing offset
  changed. Build-specific offset documented in `docs/discovery.md` for re-derivation.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.6.0`.
