# Validation Report — terrariabonker v0.11.1

**Date**: 2026-08-21
**Scope**: Spec 014 — real crafting-station names in the recipe browser.

## Summary

Recipe-browser station names now come from Terraria's own tile display names
(`Lang._mapLegendCache[MapHelper.tileLookup[tile]]._value`) instead of an item-
`createTile` heuristic that mislabeled rarer stations (e.g. tile 228 → "golf balls"
instead of "Dye Vat"). Two class statics are resolved by AOB during extraction, and
`recipes.json` is regenerated with exact names.

## Phase 3 — Tests

- **84 passed** headless. `test_station_name` updated (cache hit + "Tile #N" fallback,
  hardcoded supplement removed).
- **Live** (game pid 1632717): re-extraction named all 35 station tiles correctly and
  produced **0** "Tile #N" for real stations — Work Bench, Sawmill, Anvil, Tinkerer's
  Workshop, Ancient Manipulator, Dye Vat, Sky Mill, Furnace, Loom, Cooking Pot, Keg,
  Bone Welder, … Spot-checks: Iron Anvil @ Work Bench; Mythril Anvil @ Anvil; Frostspark
  Boots @ Tinkerer's Workshop; Ale @ Keg. The chain was validated directly: tile 17 →
  legend 21 → "Furnace", tile 18 → "Work Bench", tile 247 → "Autohammer".

## Phase 4 — Code quality

- `ruff check` → passed. `_tile_names` resolves `tileLookup`/`_mapLegendCache` by AOB
  (reusing the patcher's `Pattern` masked matcher) and reads `LocalizedText._value`;
  fails safe to "Tile #N" if a pattern is missing. The `createTile` derivation and the
  hardcoded station supplement were removed.

## Phase 5 — Security review

- No new inputs, network, or dependencies. Read-only memory over the existing `/proc`
  path; the cache is plain tile-name strings. Secrets: none.

## Phase 5.5 — Release safety

- **Rollback**: `git revert` + re-extract. Build-specific AOBs documented
  (`ce/poc_tilename.lua`); a game update degrades names to "Tile #N", never errors.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.11.1`.
