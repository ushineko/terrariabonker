# Validation Report — terrariabonker v0.2.2

**Date**: 2026-08-21
**Scope**: GUI/editor fixes — inventory edits now persist to the live copy, given
items carry real stats, more editable columns, and a game-flavored icon.

## Summary

Four fixes:

1. **Edits now save.** Root cause: three identical player copies exist and
   `pick_live` returns None while the game is paused, so edits landed on a
   snapshot. Inventory writes now apply to *all* copies (the live one takes
   effect, snapshots are inert), matching the stat-freeze model.
2. **Given items have real stats.** Setting `Item.type` alone leaves a weapon with
   zeroed stats. `give` and type-changing `set-item` now clone the pristine
   `ContentSamples` template for the type (the game keeps one per item in memory).
3. **Auto and useTime are editable** in the inventory table (they were hitting the
   wrong copy before, which read as "not editable").
4. **Icon**: an original pixel grass-dirt-block + pickaxe SVG (`assets/`), wired
   into the window, taskbar, and desktop entry.

## Phase 3 — Tests

- **43 passed** headless (2 new: template copy on give and on type-change).
- Live: `give_item(4956)` (Zenith) → damage 190, useTime 10, autoReuse 1 (real
  stats); `set_stack` writes hit all three player copies.

## Phase 4 — Code quality

- `ruff check` → passed. Inventory-mutation logic centralised in the service
  (`_all_inventories`, `_template_block`, `_place_item`); GUI/CLI unchanged in shape.
- Template copy is bounded to the Item stat block (`0x1C..0x140`), safely inside
  the (large) Item object; only scans memory when a type actually changes.

## Phase 5 — Security review

- No secrets, no network. Privilege model unchanged (sudo per operation). The
  template scan only reads game memory; the copy writes within existing Item
  objects of the player's own inventory.

## Phase 5.5 — Release safety

- **Rollback**: `git revert`; no persistent state, no schema change.
- **Additive**: behaviour fixes only; no CLI command or flag removed.

## Result

All gates pass. Approved for commit and tag `terrariabonker/v0.2.2`.
